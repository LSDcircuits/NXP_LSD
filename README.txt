NXP_LSD
A hal for use with the LPC84X, mainly focused on functions which can be used on control systems. 
The main purpose of creating this Hal is for simple and deterministic controll of signals for actuators and reading sensors,
Generally setting up Harware peripherals for projects that can be time consuming to make tests for.

The main target family is the NXP LPC series due to its proven reliability and extensive documentation from manufacuter and architecutere simplicity
allowing bugs & erros to be more trasable. / (far from completed due to school :) )
