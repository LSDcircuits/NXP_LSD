Flashing & Debugging NXP MCU (LPC 84X series)

Architecture overview:
UNIX MACHINE - > OPENOCD - > DEBUG PROBE (CMSIS-DAP/ MCU-LIK) → LPC SWD INTERFACE - > FLASH MEMORY / DEBUG

 Config File Chain:
| File	                          Purpose
| interface/cmsis-dap.cfg	       Configures the debug probe (MCU-Link on your BRK board)
| target/lpc84x.cfg	             Configures the LPC845 target chip (flash driver, memory map)
| Your custom commands	          Programming, verification, reset                      

Lpc84.cfg (target file) (OPENOCD 0.10.0+) defines:

-  Flash driver: LCP (internal flash algirithm)
-  Flash bank: Base address 0x00000000
-  IAP entry point: 0x0F001FF1 (LPC845)
-  Work area: internal flash

CMSIS-DAP
openocd 
-f interface/cmsis-dap.cfg 
-f target/lpc8x.cfg 
-c "program lpc845_project verify reset exit"

JLINK
openocd 
-f interface/jlink.cfg 
-f target/lpc8x.cfg 
-c "program lpc845_project verify reset exit"
